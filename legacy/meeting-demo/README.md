# Earlier meeting-demo UI (preserved, not maintained)

This is the previous "bi-directional meeting" prototype: listener modes, speech input, a rule-based finger-count gesture heuristic, and simulated vocabulary cards. It was replaced by the main Silent Sign app because its gesture results were heuristic or simulated rather than model predictions, and its ISL letter panel pointed at a model file that never existed.

It is kept here unchanged for reference. It is a static page: open `legacy/meeting-demo/index.html` in a browser to look at it. It is not needed to run Silent Sign.
